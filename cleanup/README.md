# cleanup/

**Post-generation repair of a raster atlas, with no ground truth to check against.**

The generator's character accuracy has a hard tail: on difficult styles a few of
the 94 cells come back malformed. This package recovers those cells *after*
generation and before vectorization, rather than trying to make the generator
perfect. `run_cleanup` in `pipeline.py` is the entry point, in two modes — FAST
generates once and inpaints what the verifier flags; QUALITY generates N times,
picks the best cell from each position, then inpaints the residual.

The hard constraint is that **production has no target font**. In eval a cell is
scored against that font's own ground-truth glyph; when a user is inventing a
typeface there is nothing to compare to. So the verifier may use only two
signals — the character each grid position is *supposed* to carry (OCR), and
whether a cell's DINOv2 embedding sits inside the atlas's own style cluster —
and it flags a cell only when both agree, because TrOCR misreads legible
stylized glyphs and repairing every OCR failure damages good cells. The design
and that guard are in
[`docs/superpowers/specs/2026-05-31-cleanup-pipeline-design.md`](../docs/superpowers/specs/2026-05-31-cleanup-pipeline-design.md).

`models.py` is the most widely imported module here: `build_dino_embed_fn` is
the project's single DINOv2 embedder, and a dozen scripts across `analysis/`
and `probes/` reach for it rather than building their own.

Run from the repo root. These are library modules, not scripts — import them
package-qualified, the way the callers do:

```python
from cleanup.models import build_trocr_ocr_fn, build_dino_embed_fn
from cleanup.pipeline import run_cleanup
```

Every module has a test in `tests/test_cleanup_*.py`.
